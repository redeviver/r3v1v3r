# ⚡ VpsPack Cyber Edition
# R3V1V3R VPSPACK

Gerenciador de VPS com interface em terminal estilo cyberpunk, focado em administração de usuários, conexões seguras e ferramentas de rede.

---

## 🚀 Funcionalidades

* 👤 Gerenciamento de usuários (criar, deletar, redefinir)
* 🔐 Controle de sessões simultâneas
* 🌐 Configuração de VPN (OpenVPN/WireGuard)
* 🧬 Tunelamento SSH seguro
* 📊 Teste de velocidade
* 🎨 Interface interativa estilo cyberpunk

---

## 📦 Instalação

```bash
git clone https://github.com/seuuser/VpsPack.git
cd VpsPack
chmod +x install.sh
sudo ./install.sh
```

---

## 🖥️ Uso

Execute:

```bash
sudo vpspack
```

---

## 🎛️ Menu Principal

* [1] Gerenciar Usuários
* [2] VPN
* [3] Tunelamento SSH
* [4] Monitoramento
* [0] Sair

---

## 🔐 Segurança

Este projeto é destinado a:

* Administração de servidores
* Acesso remoto seguro
* Estudos de redes

❌ Não é destinado a anonimato ilegal ou bypass de sistemas.

---

## ⚠️ Requisitos

* Linux (Ubuntu/CentOS/Debian)
